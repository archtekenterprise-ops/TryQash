# TryQash - Application Web

Bienvenue sur le dépôt officiel de **TryQash**. Ce projet utilise **Next.js**, **TypeScript**, **Tailwind CSS** et **Supabase**.

## Prérequis
* Node.js (version LTS recommandée)
* npm (ou le gestionnaire de paquets validé par l'équipe)

## Installation locale

1. Cloner le dépôt :
   ```bash
   git clone <URL_DU_REPO>
   cd tryqash

## Lancer le projet avec Docker
2. Construire l'image :
   ```bash
   docker build -t tryqash-app .
